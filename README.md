# NORTH — Real Estate Template

A production-ready, responsive real estate showcase built with Next.js, React, and TypeScript.

## Features

- Distinct art direction and responsive layout
- Semantic HTML, accessible labels, and reduced-motion support
- Static-first architecture with no database dependency
- SEO metadata and Vercel-ready production build
- Zero runtime dependencies beyond Next.js and React

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Data strategy

This demo intentionally uses local typed content, so it can be deployed without credentials or a hosted database. If converted into a CMS, booking, account, or admin-driven product, Supabase can be added behind server-side data access with Row Level Security.
